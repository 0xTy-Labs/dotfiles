# axdots ✦

> An Ambxst-inspired Hyprland desktop shell — rebuilt lean, typed, and GPU-ready.

**Stack:** AGS v2 (Astal) · TypeScript · GTK4 · Hyprland  
**RAM:** ~35–55 MB idle (vs Ambxst/Quickshell ~100–140 MB)  
**Target:** Arch · Fedora · Debian/Ubuntu + any Hyprland distro

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/0xTy-Labs/dotfiles/refs/heads/backbone/Desktop/install.sh | bash
```

Then add **one line** to `~/.config/hypr/hyprland.conf`:

```ini
source = ~/.config/axdots/config/hyprland.conf
```

Reload Hyprland — done.

## What's included

| Module | Description |
|---|---|
| **Bar** | Floating top bar — workspaces, clock, tray, status pills |
| **Notch** | Center pill — collapsed media strip → expanded controls panel |
| **Dock** | Bottom app dock — auto-hide, magnification, right-click menu |
| **Notifications** | Toast cards + history center panel |
| **OSD** | Volume / brightness on-screen display |
| **Calendar** | Mini month picker, toggled from clock |
| **Power Menu** | Full-screen overlay — lock/suspend/reboot/shutdown/logout |
| **Corners** | Rounded screen corner overlays |
| **Lockscreen** | Hyprlock — blurred wallpaper, large clock, auth widget |
| **Launcher** | Rofi with glass theme — apps, clipboard, emoji |
| **Theming** | Matugen wallpaper→color pipeline, hot-reload CSS |

## Architecture

```
~/.config/axdots/
├── shell.ts                 # AGS v2 entry — mounts all surfaces
├── modules/
│   ├── bar/                 # Status bar (Bar, Workspaces, Clock, StatusPills, SysTray)
│   ├── notch/               # Notch (Notch, MediaPill, Controls, Osd)
│   ├── dock/                # Dock (Dock, DockItem, DockMenu)
│   ├── notifications/       # Toasts + Center panel
│   ├── widgets/             # PowerMenu, Calendar
│   ├── corners/             # Screen corner overlays
│   └── launcher/            # launcher.rasi (Rofi theme)
├── services/
│   ├── Config.ts            # JSON config with hot-reload
│   ├── Theming.ts           # Matugen pipeline → CSS tokens
│   ├── Hyprland.ts          # IPC service (workspaces, windows)
│   └── Wallpaper.ts         # SWWW control
├── styles/
│   ├── tokens.css           # Auto-generated by Matugen (DO NOT EDIT)
│   ├── base.css             # GTK4 reset + typography
│   ├── animations.css       # Keyframes + transition utilities
│   ├── components.css       # Shared component classes
│   └── modules/             # Per-module stylesheets
├── config/
│   ├── axdots.json          # User config (edit this)
│   ├── hyprland.conf        # Source in your hyprland.conf
│   ├── hyprlock.conf        # Lockscreen
│   ├── hypridle.conf        # Idle daemon
│   └── dunst.conf           # Notification daemon
└── scripts/
    ├── theme.sh             # Matugen trigger + CSS rebuild
    ├── wallpaper.sh         # SWWW wrapper
    ├── screenshot.sh        # Grimblast wrapper
    ├── clipboard.sh         # Cliphist Rofi picker
    ├── emoji.sh             # Emoji picker
    └── toggle.sh            # AGS IPC toggle helper
```

## Configuration

Edit `~/.config/axdots/config/axdots.json`. Changes hot-reload — no restart needed.

```jsonc
{
  "bar":   { "enabled": true, "height": 32, "margin": 8 },
  "notch": { "enabled": true, "showMedia": true, "showToggles": true },
  "dock":  { "enabled": true, "iconSize": 48, "autoHide": true },
  "theme": { "matugenScheme": "tonal-spot", "wallpaper": "~/Pictures/wall.jpg" }
}
```

## Theming

axdots is **wallpaper-driven**. Set a wallpaper and the entire color system rebuilds:

```bash
# Set wallpaper + rebuild theme
~/.config/axdots/scripts/wallpaper.sh ~/Pictures/aurora.jpg

# Random wallpaper
~/.config/axdots/scripts/wallpaper.sh --random ~/Pictures/wallpapers/

# Rebuild theme only (e.g. after changing matugenScheme)
~/.config/axdots/scripts/theme.sh ~/Pictures/aurora.jpg
```

**Matugen schemes:** `tonal-spot` · `expressive` · `fidelity` · `content` · `monochrome`

## Performance notes

- **One GJS process** — all modules share a single event loop
- **Blur via Hyprland** — no software blur in CSS (GPU, not CPU)
- **Lazy widgets** — Calendar/SysMonitor only instantiated when shown
- **Event-driven services** — Network/Audio/Battery subscribe to D-Bus, never poll
- **Conditional rendering** — disabled modules never mount
